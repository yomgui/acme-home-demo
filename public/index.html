Acme Home
SYNTHETIC MCP APP DEMO

Your work, connected.

A home for your day, priorities and goals. Open the interactive dashboard through a compatible MCP Apps host, not as a standalone webpage.

Add this site's /mcp endpoint to your host, then call: 

{"name":"acme_home","arguments":{}}

The tool is bound to ui://acme-home/home.html. Launch returns the layout; each panel retrieves its own synthetic data through the same tool.

Work data and actions are synthetic. Shared mode requires no credentials; a separately configured per-user endpoint requires OpenWork sign-in. Local previews do not send messages or create requests.
